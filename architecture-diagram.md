## Data Flow

```
1. USER INPUT                          4. TAILORING (Optional)
   ┌─────────────┐                          ┌──────────────┐
   │ Job Desc    │                          │              │
   │ Resume Text │                          │  Input:      │
   └─────┬───────┘                          │  - Parsed    │
         │                                  │    Resume    │
         ▼                                  │  - Job Desc  │
2. PARSE RESUME                             └──────┬───────┘
   ┌─────────────┐                                 │
   │ LLM Call    │                                 ▼
   │ (JSON Mode) │                           ┌──────────────┐
   └─────┬───────┘                           │  Tailored    │
         │                                   │  Summary     │
         ▼                                   │  Skills      │
   ┌─────────────┐                           │  Bullets     │
   │ Structured  │                           └──────┬───────┘
   │ JSON Data   │                                  │
   └─────┬───────┘                                  ▼
         │                              ┌──────────────┐
         ▼                              │  RenderCV    │
3. BUILD CV                             │  YAML        │
   ┌─────────────┐                      └──────┬───────┘
   │ Date Norm   │                             │
   │ Phone Norm  │                             ▼
   │ Social Net  │                      ┌──────────────┐
   │ Sections    │                      │  PDF Gen     │
   └─────┬───────┘                      │  (RenderCV)  │
         │                              └──────┬───────┘
         ▼                                     │
   ┌─────────────┐                             ▼
   │ RenderCV    │                      ┌──────────────┐
   │ YAML        │                      │  Multi-      │
   └─────┬───────┘                      │  Format      │
         │                              └──────┬───────┘
         ▼                                     │
   ┌─────────────┐                             ▼
   │ PDF +       │                      ┌──────────────┐
   │ Other       │                      │  Download    │
   │ Formats     │                      │  Links       │
   └─────────────┘                      └──────────────┘
```
